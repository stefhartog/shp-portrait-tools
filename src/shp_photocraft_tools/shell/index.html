About

SHP Portrait Tools provides Skin Mask, FS & Tone, Dodge & Burn and Combine through Skin Tools, plus Crop & Expand and Patch Fill through AI Fill.

Image processing runs locally. PhotoCraft integration is optional; Combine batch processing is local-only and never runs Crop.

Theme is saved in this browser. Transfer options remain in the existing settings/preset bundle; skin-mask precache uses its existing browser preference. Calculation timings are temporary and clear when the skin-tools view reloads.
